# 客户端测试台（client）

独立的客户端进程：启动后在本机 **4000** 端口提供网页控制台，页面通过它调用服务器的功能。

**本目录不含任何服务器代码与业务数据** —— 账号、用户资料、公开卡片库、私人卡片库、对话记录全部保存在服务器上；
客户端只保留「要连接哪台服务器」这一项配置。因此整个 `Chengnuo-backend/` 目录可以单独拷到别的设备上使用。

## 目录说明

| 路径 | 作用 |
| --- | --- |
| `launcher.js` | 启动器：决定连哪台服务器 → 启动客户端进程 |
| `src/` | 客户端进程（Express）：健康检查、服务器 IP 库、把页面请求转发给服务器 |
| `public/index.html` | 网页控制台（浏览器打开 `http://localhost:4000/`） |
| `data/routing-ips.txt` | **服务器 IP 库**：记录要连接的服务器地址，带说明、可手动编辑 |
| `.env` | 本机监听地址/端口（**不含**服务器地址，改服务器请看 IP 库） |
| `start.bat` | Windows 一键启动（自动装依赖 → 启动 → 打开控制台） |

## 换到另一台设备上使用

1. **安装 Node.js 20 或更高版本**（代码用到 `fetch` 等较新特性）。
2. **把整个 `client` 目录拷过去**，首次启动会自动 `npm install`（只依赖 `express` 一个包）；
   也可以把自己的 `node_modules` 一起拷过去省去联网安装。
3. **改 `data/routing-ips.txt`**：默认那一条（`"primary": true`）就是「服务器」——把它填成**服务器所在设备的对外可达地址**
   （如 Radmin VPN / Tailscale 等虚拟局域网地址，其他设备才连得上）；本机回环 `127.0.0.1` 那条是「本地服务器」的次选。
   （也可以先启动，再到控制台的「服务器」一行里切换，见下文——那种方式立即生效、无需重启。）
4. **双击 `start.bat`**（或执行 `node launcher.js`），浏览器会自动打开 `http://localhost:4000/`。
   用你在服务器上注册过的账号密码登录即可。

`data/routing-ips.txt` 示例（顶部还有完整说明，改完保存并重启客户端生效）：

```
{"id":1,"ip":"26.103.5.180","port":3000,"name":"server","primary":true,"createdAt":"..."}   // 服务器（对外可达地址）
{"id":2,"ip":"127.0.0.1","port":3000,"name":"local","primary":false,"createdAt":"..."}      // 本地服务器（本机）
```

## 服务器地址是怎么定的（launcher.js）

优先级从高到低：

1. 命令行参数 `--server=IP:PORT`（会写回 IP 库并设为 `primary`）
2. IP 库中 `primary` 为 `true` 的那一条（即「服务器」）
3. IP 库中第一条有效记录
4. 默认：本机对外可达地址（优先虚拟局域网地址，否则局域网地址）+ `3000`

```bat
node launcher.js                            :: 用 IP 库里 primary 指定的服务器
node launcher.js --server=192.168.1.50:3000 :: 临时指定服务器（并写回 IP 库）
node launcher.js --myip=192.168.1.20        :: 指定本机地址（仅用于展示）
node launcher.js --help
```

启动时控制台会打印当前用的是哪台服务器、来源是什么、IP 库文件在哪：

```
  服务器地址   (来源)  : 192.168.1.50:3000  ← IP 库 primary（#2）
  本机地址     (客户端): 192.168.1.20:4000
  服务器 IP 库         : ...\Chengnuo-backend\data\routing-ips.txt
```

## 在控制台里切换服务器（推荐）

打开 `http://localhost:4000/`，在「账号」行下方有一行 **服务器**：

- 下拉框候选（按顺序）：
  1. `服务器（本机对外地址 · Radmin VPN）` —— **默认选项**，这台设备的服务器对外可达地址，其他设备上的客户端据此连上；
  2. `本地服务器（本机 127.0.0.1）` —— 次选，每台设备自己本地跑的那套服务器；
  3. IP 库里保存过的其它服务器地址。
- 也可以直接在输入框里填 `IP:PORT`（如 `192.168.1.50:3000`）。
- 点「切换」后**立即生效，无需重启客户端**（切换会写回 `data/routing-ips.txt` 并把它设为 `primary`）。
- 行末灰色文字显示当前服务器与本机地址。

> 切换到**另一台**服务器后，登录凭据在那边无效，需重新登录；只是同一台服务器换个地址（127.0.0.1 ↔ 局域网 IP）则无需重新登录。

## 连不上服务器时

1. 检查 `data/routing-ips.txt` 里 `primary` 那条的 `ip` / `port` 是否正确；
2. 确认服务器已启动、**服务器的 3000 端口已放通**（Windows 防火墙入站）、两台设备网络互通；
3. 只想在本机测试：在控制台「服务器」一行切到 `本地服务器（本机 127.0.0.1）`；
4. 启动器连不通时会临时回退到 `127.0.0.1` 并给出提示（**不会**改写你的 IP 库配置）。

## 注意事项

- **同一账号只保留最新一次登录**：在另一台设备登录同一账号后，原设备的登录态立即失效，页面会提示重新登录。
- **网页控制台监听 `0.0.0.0:4000`**，同网段其他人也能打开它；只想自己用就把 `.env` 里的 `HOST` 改成 `127.0.0.1`。
- 服务器重启后需要重新登录（登录凭据只保存在服务器内存中）。
- 改 `public/index.html` 只需在浏览器 `Ctrl+F5`；改 `src/` 下的代码需要重启客户端。
- 服务器上的管理类接口（`/api/ai/*`、会话列表、路由 IP 库等）只允许在**服务器本机**访问，客户端机器无法使用。
