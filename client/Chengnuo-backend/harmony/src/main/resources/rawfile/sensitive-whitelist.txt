# 智能审核白名单（放行词）
#
# 背景：敏感词库由政治口号等文本切碎生成，混入了大量中文高频常用词
#   （如「一个」「时间」「计划」「任务」「完成」「没有」「信息」「电话」…），
#   导致正常输入被系统性误拦（例：写「设一个一分钟后提醒我的」会被「一个」拦截）。
#
# 规则：本文件中的词条，若在敏感词库中存在完全相同的条目，加载时跳过该条目（不再拦截）。
#   词库其余条目（政治、毒品、色情、暴力等真实代号）不受影响。
#   本文件只做「放行」，不做「新增拦截」。
#
# 格式：每行一个词；'#' 开头为注释；匹配前统一归一化（转小写 + 删空白）。
# 生效：Node 端与设备端各一份，内容保持一致；改动后自动热重建，无需重启。
# 说明：日常只需在此追加正常词，无需改动 5 万行词库。
